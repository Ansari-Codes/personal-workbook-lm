GUIDE 01 · FIRST RUN

Install & run

The backend is a Python FastAPI application. Python is required to run PAWM. Node.js and npm are only needed when developing or rebuilding the Vue frontend.

Requirements

  • Python installed and available in your terminal.
  • Node.js and npm for frontend development (the project expects Node.js 22.18+ or 24.12+).

Run the application

Open PowerShell at the repository root. Create and activate a virtual environment, then install backend packages:

python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r Backend/requirements.txt

Start the server from the repository root:

uvicorn Backend.main:app --port 8080

Open http://localhost:8080. The health check is at /health; the interactive API reference is at /docs.

Frontend bundle

The backend serves the compiled frontend from Frontend/, which is included in this project. If you change frontend code and need to regenerate the bundle, run the build steps below before launching the backend.

Frontend development

Install Node dependencies and start Vite, or build the frontend bundle:

npm install
npm run dev

To build the frontend into Frontend/ for the FastAPI server:

npm run build

Run these commands from the repository root. Vite uses port 5173; the FastAPI app uses port 8080.

Where data goes

The web backend currently configures storage at the project’s Storage/ directory. The standalone Python storage API defaults to Documents/PAWM_DATA when created without an explicit directory; that is not the path currently selected by the web app.

Storage is local filesystem data, not a cloud backup. Protect it accordingly and make your own backups.
